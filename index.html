liteadmin apt repository

A hostable SQLite browser and editor. Like phpMyAdmin, but for SQLite.

  • Source: github.com/martijndeb/liteadmin
  • Signing key: pubkey.gpg
  • Suite: stable  |  Component: main  |  Architecture: all

1. Import the signing key

Packages and repository metadata are signed. Import the public key first:

curl -fsSL https://martijndeb.github.io/liteadmin/pubkey.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/liteadmin.gpg

2. Add the repository

Create /etc/apt/sources.list.d/liteadmin.sources (deb822 format):

Types: deb
URIs: https://martijndeb.github.io/liteadmin
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/liteadmin.gpg

3. Install

sudo apt update
sudo apt install liteadmin

The package installs to /usr/share/liteadmin. Configuration lives in /etc/liteadmin/config.json, databases in /var/lib/liteadmin/databases. Point your web server's document root at /usr/share/liteadmin.

4. Web server example (nginx)

Deny access to the config and database paths — they are symlinked inside the document root:

server {
    listen 80;
    server_name liteadmin.internal;
    root /usr/share/liteadmin;
    index index.php;

    location ~ ^/(config\.json|databases) { deny all; }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php-fpm.sock;
    }
}

5. Automatic updates (optional)

To let unattended-upgrades pick up new releases from this repository, create /etc/apt/apt.conf.d/51liteadmin:

Unattended-Upgrade::Origins-Pattern { "origin=liteadmin"; };

Verify with:

sudo unattended-upgrade --dry-run --debug

Verify a package

Key fingerprint check after import:

gpg --show-keys /usr/share/keyrings/liteadmin.gpg

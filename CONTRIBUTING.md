This is a small hobby project, with only one requirement really; Write dependency-free code so it can be self contained and hosted in the most flexible way.
Keep this in mind when contributing.

The build system is aimed at Ubuntu and Debian installations and uses xz, since newer standards are only supported on latest versions.
If you wish to contribute a new build and packaging system, make it easy to maintain and support a large set of versions of your target.

Be mindful of others, so test your features. Even better, add a test for it using the playwright scripts.
